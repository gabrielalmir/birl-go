1 Guia de Treino (Sintaxe)

Variáveis e Tipos

No BIRL-GO, você não declara variáveis, você define o peso do treino.

MONSTRO peso = 100; // int64
TRAPÉZIO altura = 1.85; // float64
FRANGO nome = "Bambam"; // string

Controle de Fluxo

Decisões rápidas como um drop-set.

ELE QUE A GENTE QUER? (peso > 80)
    // Se for monstro
BIRL
NÃO VAI DAR NÃO
    // Se for frango
BIRL

2 Exercícios Avançados

Arrays Dinâmicos

Agrupe seus exercícios em séries. Suporte completo a indexação.

MONSTRO series = [10, 12, 15];
CE QUER VER ESSA PORRA?(series[0]);

Ponteiros Brutos

Acesso direto à memória. Aponte para o músculo alvo com & e *.

MONSTRO x = 13;
MONSTRO p = &x;
CE QUER VER ESSA PORRA?(*p);

"O segredo é não parar, porra!"
